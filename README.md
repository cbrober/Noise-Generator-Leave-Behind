# Noise-Generator-Leave-Behind

Background:
This is quick build project that can be expanded upon. I am using a Raspberry Pi 4B as the base (because that is what I already had available), but this could be done with a Pi 0 or pico. 
The additional items needed are the integrating unit, I used an adafruit I2S 3W Pi hat. You will also need the speakers, I used (2) 3W 4Ohm 40mm speakers and some 24 gauge threaded wire. The final bare minimum item will be a power source, I am using an old anker power block. 

My intent is to take this out on a patrol and upon identification of the opposition forces place this build in a nearby concealed position (within auditory range). I will adjust the executable file to count down 30 minutes from boot to initiate the file loop service. The desired outcome is that this audio is heard by the opposition forces to either inform them of an inaccurate position for our forces, or put them in a hasty defensive position in order to create an exhaustive and unsustainable environment. I intend to create about a dozen of these with cheaper parts to maximize the effect. 

Initial setup considerations:
For the initial set up it is helpful to have peripherals available. 
You can do this headless, so your pi image does not need to be a full desktop. This may be more beneficial to reduce the amount of processing required and also minimize the confusion on file placement. 

Expanse ideas:
Again this was intended to be quickly built in an hour as required for the exercise I am about to do, but.... here are some things I would add if there was more time.

Motor-motion add:
This has two potential applications; one, to move the device creating a mobile source of deception; and two, the motor-motion attachment can create a more natural sound that carries farther than the speakers. (example: a rotating gear that strikes a piece of metal or other material to replicate the sound of personnel adjusting their equipment.)

Visual add:
Personnel operating under cover of darkness have a tendency to want to use their light sources. Adding an lagged intermittent light strobe to breach the darkness can add to the opposition identification of the device. 

Collection add:
While this device is primarily intended for deception, who says it cannot also serve as a collection item. The requirements for this add to the overall cost and complication of the project so I am unlikely to consider this with the time I have to work on it, but could be valuable. It would require remote device control like a cell hat or some form of radio data hat, and also be considerably more discoverable. But, this addition could also feedback into the information loop of opposition forces location.
